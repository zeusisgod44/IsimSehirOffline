# IsimSehirOffline

## Flutter (Android + iOS)

Çapraz platform çevrimdışı LAN oyunu [flutter_app](flutter_app/README.md) klasöründedir. Bir telefon WebSocket oda sunucusu olur; Bonjour/mDNS keşfi, elle IP ile katılım, eş zamanlı turlar, anonim oylama ve çoğunlukla puanlama desteklenir. GitHub Actions Flutter analizini ve oyun kuralı testlerini çalıştırır, kurulabilir Android debug APK'si üretir ve Xcode ile imzalanması için Android/iOS proje dosyalarını yayınlar.

Önceki Android Java uygulaması kökteki başlangıç arşivinde korunur.

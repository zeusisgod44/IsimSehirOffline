# IsimSehirOffline

## Flutter (Android)

Çevrimdışı LAN oyunu [flutter_app](flutter_app/README.md) klasöründedir. Bir telefon WebSocket oda sunucusu olur; Android'de mDNS keşfi, elle IP ile katılım, eş zamanlı turlar, anonim oylama ve çoğunlukla puanlama desteklenir. GitHub Actions Flutter analizini ve oyun kuralı testlerini çalıştırır, kurulabilir Android debug APK'si üretir.

Önceki Android Java uygulaması kökteki başlangıç arşivinde korunur.
